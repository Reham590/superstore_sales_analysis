# Superstore Sales Analysis

## Project Overview
This project focuses on analyzing sales and profit performance using the Sample Superstore dataset. An interactive Excel dashboard was developed to explore business performance across different categories, regions, customer segments, and time periods.

## Project Objectives
- Analyze overall sales and profit performance.
- Identify top-performing products and sub-categories.
- Compare sales performance across product categories and regions.
- Explore the relationship between discount levels, sales, and profit.
- Track sales and profit trends over time.

## Tools & Techniques
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Analysis & Visualization

## Dashboard KPIs
- **Total Sales:** $2.30M
- **Total Profit:** $286.4K
- **Profit Margin:** 12.5%

## Dashboard Features
- Sales and Profit by Sub-Category
- Sales by Category
- Sales and Profit by Discount Level
- Sales Over Time
- Top 10 Products
- Sales by Region
- Interactive filters for Segment, Region, Category, and State
